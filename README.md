> *I focus on the **Product Mindset** — building software that isn't just clean under the hood, but meaningful to business logic and user experience.*

- **Clarity over cleverness** — readable code is a feature, not a compromise  
- **Security by design** — auth and access control are first-class concerns, not afterthoughts
